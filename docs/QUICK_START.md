## 💻 Install on Your Desktop

See [INSTALLATION.md](./INSTALLATION.md) for complete step-by-step instructions for Mac, Windows, Linux, and Unreal Engine 5.

**Quick install (Mac):**
```bash
brew install node encoredev/tap/encore
git clone https://github.com/PARPUBLISHING/Unified-3D-Production-Studio.git
cd Unified-3D-Production-Studio
cd backend && npm install && cd ../frontend && npm install && cd ..
```

Then open 2 terminals:
```bash
cd backend && encore run        # Terminal 1
cd frontend && npm run dev      # Terminal 2
```

Visit: http://localhost:5000

## 🎮 Unreal Engine Integration

Full guide in [INSTALLATION.md](./INSTALLATION.md#unreal-engine-5-integration)

2. Create project: FinesseStudioVirtualProduction
3. Enable WebSocket plugins
4. Connect to Studio backend on port 8080
