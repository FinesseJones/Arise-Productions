## ✒️ Screenwriting Rules (Fountain Format)
Fountain is a plain-text format that screenwriting apps (and Scriptation) read. Keep these in mind when asking the AI to write:
- **Scene Headings:** Begin with `INT.` or `EXT.` in uppercase (e.g., `INT. LIVING ROOM - NIGHT`).
- **Character Names:** Uppercase, single line, no spaces (e.g., `DANTE`).
- **Dialogue:** Immediately follows character name.
- **Parentheticals:** Wrap in parentheses on a new line under character name (e.g., `(whispering)`).
